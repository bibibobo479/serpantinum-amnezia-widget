Первый релиз виджета Amnezia VPN для Serpantinum.

- Добавляется в штатный каталог виджетов и редактируется обычным редактором.
- Подключение/отключение выбранного профиля через нативное меню Amnezia; открытие приложения.
- Состояние трея и скорость интерфейсов `amn*`, общая служба для всех карточек.
- Цвета темы Serpantinum, русский/английский интерфейс.
- Установщик без sudo, резервная копия реестра, повторная установка и аккуратное удаление.

Проверено: Serpantinum 2.2.13, Arch Linux/Hyprland. Нужны Python 3.9+ и PyGObject/Gio. Статус «Подключён / подключается» отражает ограничение API меню, а не проверку VPN-рукопожатия. Настоящий VPN не переключался во время автоматических тестов; команды проверены на отдельной D-Bus-шине.

```bash
curl -fsSL https://raw.githubusercontent.com/bibibobo479/serpantinum-amnezia-widget/main/install.py | python3 -
serpantinum reload
```

Затем выберите **Amnezia VPN** в редакторе виджетов.
